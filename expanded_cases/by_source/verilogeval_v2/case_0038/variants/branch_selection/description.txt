
I would like you to implement a module named TopModule with the following
interface. All input and output ports are one bit unless otherwise
specified.

 - input  a
 - input  b
 - input  sel_b1
 - input  sel_b2
 - output out_assign
 - output out_always

out_assign chooses a only when both selectors are high and chooses b otherwise. out_always retains the original mapping: it chooses b only when both selectors are high and a otherwise.
